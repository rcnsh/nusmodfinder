# Interpretations register, 2026/27

Every place the sources leave a reading open, with the decision and its reason. The rules file
(`data/ng-restrictions-2026-2027.json`, built by `scripts/build-ng-restrictions.mjs`) follows these
rows, and `test/eligibility.node.test.js` has a case for each row that touches a course this year.
The oracle's author (`test/oracle/oracle-2026-2027.node.mjs`) reads this file and the sources, never the rules file or
`src/eligibility.js`.

Rows marked **Jacob** are his rulings (2026-11-10); rows marked **maintainer** are the
maintainer's. A later year's register starts as a copy of this one at
`docs/year-refresh/registers/<year>.md` (`npm run year -- next`; see [register.md](../register.md)).

## How the model reads the sources
| # | question | decision | reason |
|---|---|---|---|
| R1 | Courses not on the NG list (rule E: "case-by-case … may be available during Course registration") | closed | **Jacob** |
| R2 | NG list says semester N, NUSMods doesn't offer the course in N | open, with a note "the NUSMods timetable doesn't list it in this semester" | **Jacob** |
| R3 | `sem` unset ("either semester") | shown if NG-listed in Sem 1 or Sem 2; the R2 note if no NG semester is a NUSMods semester | the student hasn't chosen a semester yet |
| R4 | Rule D: levels 5000–6000 "NOT available to exchange students unless specified in the list below" | closed for every study level unless a department rule opens that level for that study level; levels 7000+ are closed the same way | "Specified" = a rule that says who **may** take them. No NG-listed course is 7000+; the oracle reads rule D as 5000–6000 only, so one appearing fails the oracle test and needs a decision |
| R5 | Department rules that open graduate levels | Southeast Asian Studies level 5000 for 4th-years and graduates and level 6000 for graduates; ELTS, Sociology, Malay Studies, South Asian Studies graduate courses for graduates (with an approval note); PP, BMA, BMS for graduates (partner note) | each names who may take them |
| R6 | Five departments close 5000/6000 "to undergraduate students" only (Biomedical Engineering, Built Environment, Chinese Studies, Political Science, Social Work) | still closed to graduates by R4 | the sentence closes; it names no one it opens to |
| R7 | Closed and note rules on the same course | closed wins; notes accumulate on an open course | a closure is a hard limit; notes are conditions on a course a student may take |
| R8 | Study levels | `ug1`–`ug4` (`ug4` = 4th year or later) and `grad`, required in exchange mode | **Jacob** |
