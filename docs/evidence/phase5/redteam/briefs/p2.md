## How you use the site: screen reader only
You can't see the screen. You perceive the page only through its accessibility tree (what a
screen reader reads out), and you operate it only with the keyboard. Your commands:

- `goto <path>`: type an address in the address bar, e.g. `goto /`.
- `tree`: the page's accessibility tree: every element's role, name and state, as a screen
  reader would give them (including any live status messages).
- `key <key> [times]`: press a key, e.g. `key Tab`, `key Shift+Tab`, `key Enter`, `key Space`,
  `key ArrowDown`, `key Escape`, `key Tab 5`. It prints what has focus (its role and name).
- `type <text>`: type text where the focus is.
- `focus`: what has focus now.
- `url`: the address bar. `wait [seconds]`: let the page finish.

You have no screenshots and nothing visual. If something only makes sense visually, or a
control has no clear name or role, or you can't tell what happened after an action, that is a
finding: say exactly what.
