## How you use the site: on your phone
Your browser is an iPhone 13 (a 390-pixel-wide screen) in Safari. You tap and type. Your
commands:

- `goto <path>`: type an address in the address bar, e.g. `goto /`.
- `shot` (or `shot full` for the whole page): a screenshot of the screen; open the file it
  names to look. This is how you see the page.
- `read`: all the text on the page (as if you read it top to bottom).
- `tap <role> <name> [n]`: tap the element with that role whose name contains `<name>`
  (roles: button, link, radio, checkbox, textbox, searchbox, combobox, tab, option…); `n`
  picks the n-th match counting from 0. Quote names with spaces: `tap button "Sem 1"`.
- `fill <role> <name> <text>`: type text into that box (replacing what's there).
- `select <label> <option>`: choose an option in a drop-down.
- `key <key>`: press a key on the phone keyboard (`key Enter` is "Go"). `type <text>`: type.
- `scroll down|up|top|bottom`: scroll. `back`: the back gesture. `url`: the address bar.
  `wait [seconds]`: let the page finish.

Look at screenshots to see what is where, as on a real phone. If something doesn't fit the
screen, is hard to tap, or you can't find it, that is a finding: say exactly what.
