NUS on exchange for the **full year of 2027/28** (Semester 1 and Semester 2). You will be in your

## How you use the site: a phone, keyboard only
Your browser is on a phone with a 390-pixel-wide screen. You can see the screen, but you use the
page only with a keyboard (a Bluetooth keyboard paired to the phone): no tapping, no mouse.
Your commands:

- `goto <path>`: type an address in the address bar, e.g. `goto /`.
- `key <key> [times]`: press a key, e.g. `key Tab`, `key Shift+Tab`, `key Enter`, `key Space`,
  `key ArrowDown`, `key Escape`, `key Tab 5` (presses Tab 5 times). It prints what has focus.
- `type <text>`: type text where the focus is.
- `focus`: what has focus now.
- `read`: all the text you can see on the page (as if you read the screen top to bottom).
- `shot` (or `shot full` for the whole page): a screenshot; open the file it names to look.
- `url`: the address bar. `wait [seconds]`: let the page finish.

If you can't reach or operate something with the keyboard, or it doesn't fit the screen, that is
a finding: say exactly what.
