## How you use the site: a laptop
You use a laptop with a mouse and keyboard. Your commands:

- `goto <path>`: type an address in the address bar, e.g. `goto /`.
- `click <role> <name> [n]`: click the element with that role whose name contains `<name>`
  (roles: button, link, radio, checkbox, textbox, searchbox, combobox, tab, option, heading…);
  `n` picks the n-th match counting from 0. Quote names with spaces: `click button "Add to"`.
- `fill <role> <name> <text>`: type text into that box (replacing what's there).
- `select <label> <option>`: choose an option in a drop-down.
- `key <key> [times]`: press a key, e.g. `key Enter`, `key Tab`, `key Escape`. It prints what
  has focus. `type <text>`: type where the focus is. `focus`: what has focus now.
- `read`: all the text you can see on the page (top to bottom).
- `shot` (or `shot full` for the whole page): a screenshot; open the file it names to look.
- `scroll down|up|top|bottom`, `back` (the browser's Back button), `url` (the address bar),
  `wait [seconds]` (let the page finish).
