# docs

The project was built in gated phases, each with a written plan, an exit check and the evidence
behind it. These files are that record. For what the site is, start at the [README](../README.md);
for how it runs, [REFERENCE.md](REFERENCE.md).

| Path | What it holds |
|---|---|
| [REFERENCE.md](REFERENCE.md) | API routes, how a search is answered, deploying, re-ingesting, cost, data sources, known limits |
| [launch.md](launch.md) | Before any post about the site, and what to do when it is down |
| [PLAN.md](PLAN.md) | The phases, their status and exit gates |
| [CRITERIA.md](CRITERIA.md) | Success criteria SC1 to SC10 |
| [PROGRESS.md](PROGRESS.md) | The running log |
| [FINDINGS.md](FINDINGS.md) | Every review finding and how it was settled (checked by `npm run check:findings`) |
| [decisions/](decisions/) | Architecture decision records |
| [plans/](plans/) | One plan per phase |
| [evidence/](evidence/) | Measurements, red-team runs and exit write-ups per phase |
| [design/](design/) | Design mockups |
